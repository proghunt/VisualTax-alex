What's New in T4T5-2024

'Draft' release of the T4T5-2024 as of December 21, 2024

PROGRAM NOTES: Not for filing to CRA


- This early release of the program is in Draft format pending final review


- A production version with Print and Internet filing will be issued mid to end of January 2024


- You cannot File or Efile a T4T5-2024 tax return with this version. .

- The DRAFT banner is printed on every form of this program .and Internet filing is disabled for now

- Updates will be posted on our web site as new material becomes available and released via our web site. You will be informed of changes via the Alerts and Notification window as you open the VT-2024 program.

- The CRA Guides have been released by CRA and they are included now in the program

- Ensure that you accurately define the Data Directories via the top menu tab Configure -> General Options -> Data directories before you start creating new returns or rolling over the tax returns of last year.

- Rollover: This version will allow you to Rollover your Employers and Slips from last year..
