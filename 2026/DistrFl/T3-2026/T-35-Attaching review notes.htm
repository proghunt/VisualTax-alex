Attaching review notes 
Steps

Attaching a Review Mark to a data field

A review mark can be used as a way of highlighting items that need your attention before finalizing the return.
Adding a review mark: Right click on a data cell and select 'Set/Reset Review Mark'. It is a toggle switch (on or off). The data field will turn red upon setting it. You may place review marks on any number of items you want, and in as many forms you want.
Removing a review mark: Right click on a data cell that already has review mark. Then select 'Set/Reset Review Mark'. 

Finding the review marks you placed on all forms: The Audit Wizard lists all the Review Marks you placed on the forms. Just click on any item on the list.

Attaching a Note to a data field

Adding a Note: Right click on a data cell and select 'Attach Note'. You may place notes on any number of items you want, and in as many forms you want.
Finding the Notes you placed: The Audit Wizard lists all the attached notes. Just click on any item on the list.

Removing a Note: Find the Notes form, Right click on it and select 'Clear Current Page'.

 

Other ways of recording notes and reminders:

Visual tax provides several ways to record notes and reminders for each tax return prepared.
Private Notepad (Press F2, See Private Notepad under worksheets). This form can be used to record notes pertaining to the return that would be useful during the current or future years. The program will carry this information forward from year to year. Normally this form is not sent to CRA. It may contain confidential information that the preparer entered for his own use... 
Additional Information form: Press F2 and see Additional information under the Admin section. This form can be printed out and given to the client as a reminder of information he should supply before the return can be finalized.
Preparer notes: This is a brief type of note that the preparer attaches to a return during the Save return operation. The note will be displayed on the listing of the clients during the Open return operation
Preparation status: The preparer can attach a status of preparation for the return during the Save return operation
