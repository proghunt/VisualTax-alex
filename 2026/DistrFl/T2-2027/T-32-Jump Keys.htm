Jump Keys
Steps

Jump keys are keyboard keys that provide shortcuts to the more commonly used forms or functions.

When you use jump keys, you can speed up your work by avoiding the use of the mouse while you are editing tax returns.

The program supports the following Jump Keys:

In Key sequence

In Form/Function sequence

General (Function Keys)

F1 : Help
F2 : Forms Index
F3 : Save the return (Also Ctrl S)
F4 : Tax Summary
F5 : Warnings (Wizard toggle)
F6 : Find form or Line No
F7 : Previous Form
F8 : Previous Return
F10 : Main Menu
F12 : Alphabetical Forms Index
