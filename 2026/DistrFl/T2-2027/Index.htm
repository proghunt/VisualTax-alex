General program changes 

IMPORTANT NOTE: Due to the data Base changes caused by year 2000 you must create a new data directory using the 'Config | Data Directories' item of the main menu. Any returns, old o new must be saved on this new data directory.

32-bit conversion: The 2000  program has been built with the 32-bit instruction set. This means greater memory addressability and accessibility to more features available only in Windows 95 and higher. The program will not run under Windows 3.1 or earlier versions.

Internet Access: Access the Internet directly from the main Menu of the program. Just click on the Internet globe icon provided on the main menu.

In addition you can access our Web site right from this page by clicking on the VisualTax icon.

This allows you to download updates or browse the Internet without leaving the program.

Ensure that your Browser is NOT set to ‘work off-line’ otherwise the pages you see is what may be sitting on your hard drive as opposed to a live connection. Also set your browser options to ‘always refresh’ when connected to the Internet.

Y2K compliance and Date format: All dates are expressed in YYYY-MM-DD in all internal and external storage, including the Client Data Base. This ensures better compliance to the year 2000 change. Previous year's programs preferred a M/D/YY format of the short year in the control panel. This program will work with any windows supported date format. 

Saving tax returns: Due to date differences between this version and previous releases of the program data base it is strongly recommended that all returns calculated by this program are saved on a directory created by this program, even if it is a 1999 year end.  This change should be made in the data directory of the 'Save as' window.

Tree-view forms display: A new hierarchical style of displaying the forms has been introduced. The forms are displayed on a panel sitting to the left of the form. The width of the panel can be reduced by dragging the vertical line horizontally. This feature can be disabled (see Config | Other Options). The forms displayed follow a sequence of income types, deductions, taxes and administrative forms. You may find it useful depending on your style of operation. 

The other four styles of forms display are also maintained: 

- Forms (Icon or F2 key)

- From the TSUM form which acts as a menu

- By double clicking on linked fields.

Provincial Rates (other than Ontario and Alberta) can be changed at will (see Config | Provincial Rates)

EFile The Federal EFile will be a combined Federal/Ontario/Alberta EFile program, but no new date has been set yet.

Ontario D-file (File on disk): For corporations subject to CMT and Corporations with Total Assets greater than $5 Mil or Total Revenue greater than $10 Mil. Ontario needs the CT23 to be sent on diskette. We will not provide this facility until the EFile takes effect. In the meantime the only way to file such a return is to copy the figures from the program generated CT23 into the actual CT23 form provided by the Ontario Ministry of Finance.

Announcements by CCRA (formerly Revenue Canada)

Federal: Canada Customs and Revenue Agency (CCRA) has not yet released any material for 2000 year ends. It is expected to release a few new forms after February 2000.

In the meantime, it stated that it will accept 2000 year end returns based on the 1999 tax forms.

The date for the Corporate EFile is also expected to be announced by CCRA sometime in the first quarter of 2000.

Ontario: The Ontario Ministry of Finance is planning to release new CT23 forms towards the end of February-beginning of March based on the May 99 budget.

The Ontario IDSBC rate for 2000 is set to 7.5% and the Surtax at 5%. These are included in the program already (on a proration base).

The Ontario Capital Tax is undergoing changes with new threshholds of taxable capital as shown below:

Before May 5, 1999 :   $2.3 Mil

May 5, 1999  -  Dec. 31, 1999 : $2.4 Mil

Jan. 1, 2000 - Dec. 31, 2000 : $2.8 Mil  

The above changes have not been included in this release of the program. If you have returns with large taxable capital you should call the Ministry of Finance for details and override the Capital tax on CT23 page 7. We will include the calculations once they become available.
