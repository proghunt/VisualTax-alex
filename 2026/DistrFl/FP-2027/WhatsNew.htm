32-bit: The FP-2000  program is a 32-bit based program. This means greater memory addressability and accessibility to more features available only in Windows 95 and higher. The program will not run under Windows 3.1 or earlier versions.

Tree-view forms display: A new hierarchical style of displaying the forms has been introduced. The forms are displayed on a panel sitting to the left of the form. The width of the panel can be reduced by dragging the vertical line horizontally. This is only an option that can be suppressed at will. (Click on the Desktop menu item).

If you suppress the display of the forms display, then you have to use the Forms Icon (or the F2 key)

Client letters Rich format: Client letters can now be designed with any fonts and font sizes plus color (if you have a color printer).  In addition, you can have a unique template for any of your clients. This means you can have a different letter for any of your clients. The program keeps track of the letter templates that have been saved specifically for a given client.

Client data base: The underlying Data Base is using  the Microsoft Access Jet Engine. The Data Base is called FPClients

This data base holds data for all clients in an office. There are no individual files for each client.

The Data Base is configured once using the BdeAdmin.EXE program distributed on the CD

Raw Funds Data: This large database (about 60 megabytes) holds data for more than 1400 mutual funds and it is distributed with the program under license from Southam Inc.

The data base is referred to in this program as FundData

The FundData database is configured once using the BdeAdmin.EXE program available on the CD

 

Fund data updates

Updates to the fund data should be arranged with Microsophic Inc.
