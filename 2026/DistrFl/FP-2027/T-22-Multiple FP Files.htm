Multiple FP Files
Steps
VisualFP can open and handle multiple FP files at the same time. Depending on your computer memory it can easily handle 15 returns loaded concurrently. 

Press Ctrl N to open a new return or Ctrl O to open an existing return. Press Ctrl N again to open another. You will notice the following. All concurrently opened return are listed on the left panel, and each return will have its own color. The color can be changed using the color grid provided on the upper hand corner in the desktop section of icons

Change the active return (Swap the returns): Press F8 or Click any of the listed returns.

Close a return: Click the close icon (in the File Management section of the desktop) or the red X icon on the upper right hand corner of the form.
