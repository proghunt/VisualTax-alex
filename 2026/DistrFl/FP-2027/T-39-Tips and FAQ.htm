How do I transfer a FP plan done on a laptop into the main machine?

Step 1. Copy the FP file from the lap top data directory into the data directory of the main machine.

Step 2. If the FP file already existed on the main machine then this step is not required. You just use the "open' command and the up-to-date file shows on the Client book.

If the FP file is a brand new one prepared on the other machine the return will not show on the Client book. In this case, use the 'File | Open File Name' and find the file of the new file. Double click on it and that opens up the file. Once you save the file it will start appearing on the Client Book.
