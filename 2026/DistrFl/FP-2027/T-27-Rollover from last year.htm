Rollover data from last year
Steps

Feature Not currently available

 

1. Enter Last Year's Data Directory in the Configuration window: Click on Configure | General Options | Data Directories and  enter the data directory you used last year. It is recommended that you click the Browse button and navigate the directories until you locate the data directory you used last year. That data directory should come into the box called 'Last Year's Data Directory'.

2. Click on Exit and Save configuration data

Steps 1 and 2 are required only once. From this point on you can always use the Roll-over function.

3. Click on the Roll-Over icon and Select the tax program you used last year

4. Double click on any one of the tax returns showing on the Roll-over window. The program will roll-over the data from last year to this year and it will display the file in VisualFP. You can save it or continue working on it.
