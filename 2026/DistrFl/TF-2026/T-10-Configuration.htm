Configuration
Steps

Configuration is important for the smooth operation of the program.

1. Click the Configure item of the main Menu (at the top line)

2. Click each tab of the Configuration window and complete all data boxes shown

The program uses 'default values for most configuration items. Some items are important from the very beginning:

- Preparer info

- Defaults/Tax returns such as the Province and City for most of your clients

3. Click the Exit button and Save the configuration data

 

For more details click the 'Help Index' and select 'Configuration'.

 

The configuration data need to be completed once. But you can change them at will any time.
