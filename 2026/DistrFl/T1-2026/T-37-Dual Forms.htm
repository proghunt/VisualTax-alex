Dual Forms Display
Steps

It allows you to view concurrently this year's and last year's forms and data.

 

Prerequisites:

- You must have entered last year's data directory in the Configuration window

- Last year's returns must have been prepared with VisualTax

 

Once the above is satisfied:

1. Right click on the body of any of the forms shown and select 'Show Last Year's data'. (do not right click a data box)

The program will open last year's form (in different color) and show you the data used. The program in effect opens last year's return and the two returns are now listed in the 'Returns' section of the Wizard panel.

2. Switch the forms: You can go back to the current year's form by clicking the current return listed in the 'Returns' section of the Wizard panel.

3. Tile the windows:  Optionally you may want to click 'Tile'. This allows you to see concurrently all opened forms (horizontally or vertically).

 

You should not change last year's data. The program will not save it.

You can close and re-open last year's return any time during preparation.
