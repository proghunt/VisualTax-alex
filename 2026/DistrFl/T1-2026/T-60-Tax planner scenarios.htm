Tax Planner/Multiple scenarios
Steps

The Tax Planner is only available in the Power Version of the program.

The tax planner should be used ONLY when you want to see projections for the next taxation year. If you only want to create scenarios for the current  taxation year, you can do it by saving the scenarios on a folder such as C:\T1-2008\PlayFolder (Change the Directory on the Save As' window and also the file name if you are using multiple scenarios such as nnnnnnnn.vP1 or nnnnnnnn.vP2 etc ).

 

1. Click on the TaxPlanner item of the main menu and Set Current return to Tax Planner mode. This converts the current return to a tax plan. All data from your current return are used and the return is calculated using the selected tax planning rates. If you open a previously coupled return you must set both spouses to Tax Planner Mode. 

2. Select tax rates: This is a toggle that switches the rates from the current year to next year (i.e. from 2008 to 2009) or from next year to current year. You can also change the tax rates by clicking on the red 'xxxx planner'.

Notes:
-  Enter expected income and deductions and Use the TSum button for quick review of tax liability or the FSUM for coupled returns or the Tax Status line that also shows the Family Refund or Family Owing amount. 

- Saving the Tax planner data: Use the F3 key. When you save a tax planning return it is saved on the Tax Planner folder as defined in the Configure | General Options | Tax Planner directory. You could create multiple planning scenarios and save each scenario. To differentiate them, you can use different file name in the 'Save as' window: i.e. the first scenario can be saved as nnnnnnnn.nP1, the second nnnnnnnn.nP2, etc. (nnnn... is the SIN of your client).

- Opening an existing Tax Plan: To open any of these tax plans, open the Client Book and check the box called ‘Tax Plans’.

- You can Open all Saved scenarios and process then concurrently. The R-Sum screen can be handy for comparison purposes.
