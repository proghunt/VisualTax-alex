Efiling 
Steps

There are two methods of Efiling via Internet connection to CRA.

  • EFILE On-Line (EOL) : The Efile On-line is done one return at a time.

  • EFILE On-line Plus (EOLP): The EFILE On-line PLUS is batch Efiling of up to 60 returns at a time.

The Help Index contains detail operations for each method of Efiling.

Steps briefly:

EFILE On-Line (EOL): Open a return, click the EfileOnline item of the menu and select 'Efile Online (Current return)'

EFILE On-line Plus (EOLP): When you save a return, in the 'Save as' window, set the Efile status to 'Ready for Efile'. Once you prepared a sufficient number of 'Ready to file' returns, you can transmit them in batch mode via the EOLP method. Simply, click the EfileOnline item of the menu and select 'Efile Online PLUS (Batch)'
