Open a new return, enter data, save it, print it, close it
Steps

1. Click on the 'New' icon of the menu or press Ctrl N.

The forms Index will be displayed. Double click on any form you need to complete. The program by default will open an empty T3 return. 

Fields that are identified with a yellow color need to be entered. The Audit Wizard will show mandatory items that need to be entered/corrected before a return can be saved.

2. Enter data on the forms.

3. Save the return: Press Ctrl S (or F3 or click on the Save icon).

4. Print the return:  Press Alt P and select current form or current return

5. Close the return: Press Ctrl F4 (or click on the Close button of the menu).
