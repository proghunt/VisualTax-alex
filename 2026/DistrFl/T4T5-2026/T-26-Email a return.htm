Email a return
Steps

You can Email the raw data of a tax return to any Email address.

The recipient must have the VisualTax program in order to open the return.

The recipient will copy the attachment into his VisualTax Data Directory and then use File | Open By File Name to Open the tax return.

 

1. Select a return on the Most Recent returns (Main Menu) or from the Client Book (via Open)

2. Click the 'EMail' button
