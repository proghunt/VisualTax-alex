General program changes 

This program is approved for EFile and paper filing of 1999 tax returns. 

Multi-Office/Multi-user version: Click for description

32-bit: The1999  program is a 32-bit based program. This means greater memory addressability and accessibility to more features available only in Windows 95 and higher. The program will not run under Windows 3.1 or earlier versions.

Internet Access: Access the Internet directly from the main Menu of the program. Just click on the Internet icon provided on the main menu. Ensure that the  'Work Offline' item under 'File'  is not checked, so you always connect to the remote Internet page.

In addition you can access our Web site right from this page by clicking on the VisualTax icon..

Alternatively you can use the Internet connection items under the Help item of the main menu. This allows you to download updates or browse the Internet without leaving the program. If you download an update for the running program, ensure that you exit the program before applying the update.

Y2K compliance and Date format: All dates are expressed in YYYY-MM-DD in all internal and external storage, including the Client Data Base. This ensures better compliance to the year 2000 change. Previous year's programs preferred a M/D/YY format of the short year in the control panel. This program will work with any windows supported date format. 

Help System: We are moving away from the traditional windows help system, and towards an HTML based help system. In fact, this page is a HTML type of help page.

Tree-view forms display: A new hierarchical style of displaying the forms has been introduced. The forms are displayed on a panel sitting to the left of the form. The width of the panel can be reduced by dragging the vertical line horizontally. The forms displayed follow a sequence of income types, deductions, taxes and administrative forms. You may find it useful depending on your style of operation. 

The other four styles of forms display are also maintained: 

- From the TSUM form which acts as a menu

- Alphabetically

- Interview mode (pre-selection of forms)

- By double clicking on linked fields.

EFile Icons: Special icons have been provided for the most useful EFile operations

Export Discounting data: A general template is provided (ExportTpl1.Txt) which allows you to export data from discounted returns. The template can be modified and saved under any valid file name in the directory of your choice.

Client letters Rich format: Client letters can now be designed with any fonts and font sizes plus color (if you have a color printer).  In addition, you can have a unique template for any of your clients. This means you can have a different letter for any of your clients. The program keeps track of the letter templates that have been saved specifically for a given client.

Merge Client Data Bases: You can merge one or more client data directories into one. The program copies the individual tax returns into the destination directory and creates a combined listing of all clients in the destination directory. The EFile status is maintained during this operation.

Form Changes by Revenue Canada

Schedule 2 (Transfers from spouse) has been redesigned by Revenue Canada.

Schedule 5: Schedule 6 (Dependants) and Schedule 12 (Caregiver) have been combined into S5 now. It is automatically prepared by the program. We still maintain a Caregiver worksheet but it is not an official schedule any longer.

Schedule 7 and RRSP:  Schedule 7 has been changed to accommodate the Lifelong Learning Plan (LLP). Schedule 7 is now more comprehensive so part of our RRSP form has been eliminated. Our RRSP form is simply used to calculate or enter the RRSP deduction room.

Ontario tax credits: There is is only one form now. The special form for seniors has been eliminated

RC71  discounting transaction: The full format is introduced this year.
