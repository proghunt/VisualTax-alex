Release Notes for Embarcadero ™ Technologies FireDAC

Our goal with FireDAC is to provide you with the best high-speed native data access layer available for Delphi, C++ Builder, and RAD Studio. These Release Notes contain a few guidelines that you should follow in order to properly install and get started with FireDAC. More information about the product is available at FireDAC Home Page.

1. Delphi, C++ Builder Installation

The installer automatically installs FireDAC in the Delphi XE4 and C++ Builder XE4 IDEs. For older versions of the IDEs, you can run the installer with the /SHOWIDE command line parameter.

2. SynEdit Integration

FireDAC uses SynEdit for advanced query editing, including sytax highlighting in the design-time editors. To enable SynEdit integratin you should download and install SynEdit into Delphi IDE.

3. Sample Projects

The sample projects are included in the \Samples folder of your FireDAC install. All projects are using FireDAC Demo Database, which must be installed on your database server.

4. Help Files

The help files in PDF, Html Help and Help2 formats are included in the \Help folder of your FireDAC install. Or the Online Help may be used.

5. Where To Go From Here

To get started using FireDAC, please read the Getting Started articles. And look for the demos in the Samples\Getting Started folder.
