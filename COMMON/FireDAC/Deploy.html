Deploying Embarcadero ™ Technologies FireDAC Applications

This file provides information on deploying database applications that use FireDAC.  We recommend you read the entire contents of this file prior to deploying FireDAC.

1. General deployment requirments

When deploying applications that use FireDAC as runtime packages, be sure to include the required BPLs with the distribution.

2. FireDAC redistributable files

FireDAC files that may be redistributed with an application include those listed below.

  • AnyDAC_ComI_*.bpl
  • AnyDAC_Comp_*.bpl
  • AnyDAC_GUIxForms_*.bpl
  • AnyDAC_Phys_*.bpl
  • AnyDAC_PhysTDBX_*.bpl
  • AnyDAC_PhysODBC_*.bpl
  • AnyDAC_PhysMSAcc_*.bpl
  • AnyDAC_PhysMSSQL_*.bpl
  • AnyDAC_PhysDb2_*.bpl
  • AnyDAC_PhysASA_*.bpl
  • AnyDAC_PhysADS_*.bpl
  • AnyDAC_PhysMySQL_*.bpl
  • AnyDAC_PhysOracl_*.bpl
  • AnyDAC_PhysIB_*.bpl
  • AnyDAC_PhysPg_*.bpl
  • AnyDAC_PhysSQLite_*.bpl
  • AnyDAC_PhysOracle_*.bpl
  • ADAdministrator.exe

3. Royalties

No royalties or other per-installation fees are required for the redistribution of FireDAC with applications. Further, you are not limited in the number of times FireDAC may be redistributed.

4. Limitation on Redistribution

FireDAC may only be redistributed with applications created using RAD Studio, Delphi and/or C++Builder Professional, Enterprise, Ultimate or Architect license, and then only for the purpose of use with these applications.

5. FireDAC Administrator

The installation of FireDAC includes the configuration utility FireDAC Administrator. Its use with deployed database applications that use FireDAC is authorized.
